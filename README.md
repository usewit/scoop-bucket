# Wit for Scoop

[Scoop](https://scoop.sh) bucket for [Wit](https://www.usewit.app), the editor for books, essays and scripts.

```powershell
scoop bucket add usewit https://github.com/usewit/scoop-bucket
scoop install usewit/wit
```

Update with `scoop update wit`. The manifest follows the
[GitHub releases](https://github.com/usewit/wit/releases).
